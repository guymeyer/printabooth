# Visual Language: Scandinavian Assembly Instructions

## 1. Overall aesthetic

Establish a cohesive illustration system inspired by classic IKEA flat-pack furniture assembly manuals.

The aesthetic should feel:

- **Functional:** Every visual element communicates something useful.
- **Minimal:** Remove anything that doesn't improve comprehension.
- **Universal:** Illustrations should be understandable without written instructions.
- **Friendly:** Approachable, slightly playful, and never overly technical.
- **Precise:** Consistent line weights, geometry, spacing, and visual hierarchy.
- **Timeless:** Avoid contemporary illustration trends, decorative flourishes, or visual effects.

The goal is not to recreate IKEA's proprietary artwork, but to establish an original visual language informed by the same principles.

## 2. Illustration style

All illustrations must follow these rules.

**Linework**
- Black outlines on white or transparent backgrounds.
- Consistent stroke thickness throughout.
- Rounded line caps and joins where appropriate.
- Smooth, simplified contours.
- Minimal internal detail.
- No unnecessary overlapping or decorative strokes.
- Avoid excessive geometric perfection that makes characters appear robotic.

**Color**
- Default to pure black and white.
- White or transparent interiors.
- No gradients, shadows, textures, or dimensional lighting.
- A single optional accent color may be introduced for product-specific emphasis.
- Accent colors must never be required to understand an instruction.

**Depth and perspective**
- Use flat 2D illustrations as the default.
- Introduce simplified isometric or three-quarter perspective when necessary to communicate spatial relationships.
- Avoid realistic perspective distortion.
- Maintain consistent object proportions across instructional steps.
- Use dashed outlines to indicate hidden, previous, or future positions.

**Detail**
- Depict only the features necessary to identify an object or communicate an action.
- Simplify complex objects into recognizable silhouettes.
- Do not draw realistic materials, surface textures, fabric, or lighting.
- Maintain legibility when illustrations are displayed at small sizes.

## 3. Instructional composition

Treat every illustration as a visual explanation rather than a decorative image.

**One primary action per frame.**

Each instructional frame should communicate:
1. What object or component is involved.
2. What action the user should perform.
3. Where or how the action should occur.
4. What the expected result looks like.

Avoid introducing unrelated objects or competing actions within the same frame.

Use generous negative space to separate the character, objects, and instructional symbols.

Favor simple compositions with a clear focal point.

## 4. Visual instruction vocabulary

Establish a consistent collection of instructional symbols.

| Element | Meaning |
|---|---|
| Solid arrow | Direction of movement |
| Curved arrow | Rotation or turning |
| Dashed outline | Previous, alternate, or future position |
| Dashed line | Alignment or movement path |
| Magnified circle | Detail requiring attention |
| Checkmark | Correct action or outcome |
| Cross | Incorrect action |
| Exclamation mark | Caution or important information |
| Question mark | Confusion or assistance |
| Sequential numbering | Ordered steps |

These symbols must share the same visual weight and illustration style as the character.

Avoid mixing unrelated icon libraries with the instruction system.

## 5. Character integration

The mascot should appear as an active participant in the instructions.

Its purpose is to demonstrate, explain, guide, warn, and reassure.

**Behavior**
- Use exaggerated but recognizable gestures.
- Prefer clear body language over detailed facial expressions.
- Maintain consistent body proportions across all scenes.
- Let the character interact directly with depicted objects.
- Ensure that gestures communicate intent without accompanying text.

**Personality**
- Calm and helpful by default.
- Mildly humorous when illustrating mistakes.
- Expressive through posture rather than excessive facial detail.
- Never sarcastic, intimidating, or overly emotional.

The character should feel like a helpful companion who exists within the instructional world, not a decorative mascot pasted onto the interface.

## 6. Panels and step-by-step sequences

Use a modular panel system similar to printed assembly manuals.

- Each panel represents one action or concept.
- Maintain consistent padding and spacing.
- Use simple, unobtrusive borders only when necessary.
- Place step numbers consistently.
- Keep objects visually aligned across sequential panels.
- Maintain consistent camera angle unless changing perspective improves comprehension.
- Use arrows and positional changes to show progression.

Whenever possible, keep the same objects in approximately the same positions between consecutive steps.

This allows viewers to understand what changed without interpreting an entirely new composition.

## 7. Technical and object illustrations

When illustrating devices, interfaces, tools, or other products:

- Simplify their physical construction.
- Preserve defining features that make them recognizable.
- Avoid branding unless explicitly required.
- Show screens and interfaces using simplified rectangles, lines, and essential controls.
- Use exploded views only when showing assembly or component relationships.
- Avoid realistic renders and unnecessary surface detail.

Characters and objects must appear to belong to the same illustration system.

A detailed technical illustration next to an extremely simplified character should never feel visually disconnected.

## 8. Motion and animation

If animations are introduced, maintain the appearance of printed assembly diagrams brought to life.

- Prefer short, purposeful motions.
- Animate arrows, rotation, positioning, and gestures.
- Avoid bouncing, squash-and-stretch, or exaggerated cartoon physics.
- Use subtle transitions between states.
- Preserve the character's proportions throughout animations.
- Support reduced-motion preferences.

Animation should clarify an action, not become the focus of attention.

## 9. Things to avoid

Never introduce:

- 3D rendered characters
- Photorealistic objects
- Shading, gradients, or drop shadows
- Sketchy or hand-painted textures
- Comic-book styling
- Detailed facial anatomy
- Decorative backgrounds
- Unnecessary color
- Inconsistent perspectives
- Multiple competing focal points
- Generic emoji replacing instructional symbols
- Unrelated icon styles
- Excessive text labels

## 10. Design validation

Before accepting any new illustration, verify:

1. **Clarity:** Can the intended meaning be understood without text?
2. **Consistency:** Does it visually belong to the established character and illustration system?
3. **Simplicity:** Could any element be removed without losing meaning?
4. **Hierarchy:** Is the most important action immediately recognizable?
5. **Scalability:** Does the illustration remain legible at its intended display size?
6. **Originality:** Does it preserve the system's independent character identity rather than reproducing existing branded artwork?

## Guiding principle

**Illustrate the minimum necessary to communicate the maximum meaning.**

Every line should serve a purpose. Every gesture should communicate intent. Every instructional frame should feel like part of the same visual language.

The result should resemble a coherent, modern, Scandinavian-inspired instruction manual translated into a reusable digital design system.
